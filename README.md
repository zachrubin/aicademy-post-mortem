# aicademy post-mortem

A static, single-page retrospective of aicademy (2023–2026), an AI-powered study platform.

Everything the site needs is in `public/`: one `index.html` with inline CSS and JS, plus `favicon.svg`. There is no build step. Fonts load from Google Fonts.

## Sources

Content comes from aicademy's 2023–2024 pitch decks, ads and data model. Traction figures are lifetime totals (2023–2026).
